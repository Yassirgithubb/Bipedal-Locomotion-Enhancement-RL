You can use leggedgym on the Euler Cluster with RSL shares.

To do so, you first need to ask for access with the following content via E-Mail


Write an e-mail to `jonfrey@ethz.ch` and your supervisors in cc with the following information:

**Subject**: 

    Student Access to Euler Cluster

**Content** :

    Hello,
 
    I am conducting my <project_type> supervised by <supervisor_name>. 
    I have discussed the compute budget available for this project with my supervisors. 
    I am using the available resources mindfully.

    Student-Name: Firstname, Lastname
    ETH-Shorthand: firlas
    ETH-Mail: firlas@student.ethz.ch
    Start Date: DD.MM.202x
    End Date: DD.MM.202x


    Best regards,
    Firstname

While the access is pending, you can already set up your account on the cluster and build the docker and singularity file from the *containers* folder. 

A tutorial for this is available [here](https://bitbucket.org/leggedrobotics/cluster-workflows/src/main/isaacgym_workflow/).
